## Common problems
**The "Present PDF" button doesn't appear.** Click the PDF once so it is selected, and make sure only that one file is selected. The button hides for folders, non-PDF files and multi-selections. Reload the Drive tab after installing or updating.

**"This file did not come back as a PDF."** Make sure you're signed in to Google in this Chrome profile and can open the file. If the owner disabled downloading for viewers, DriveSlide can't present it. DriveSlide never bypasses Drive's access controls.

**The right-click item is missing.** It depends on Drive's page markup, which Google can change. Use the "Present PDF" button, or the toolbar icon, instead, and please report it.

**The slideshow won't go fullscreen.** Press `F`, or the ⛶ button. Chrome only allows fullscreen after a click or key press.

**Nothing happens after I reloaded the extension.** Reload the open Drive tab so its page script reconnects.

## What DriveSlide does with your data
Nothing leaves your browser except the request to Google for the file you chose. See the privacy policy.
