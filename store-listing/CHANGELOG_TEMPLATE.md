# Release notes template

Copy a block into `CHANGELOG.md` (repo root) and into the store's "What's new" field for each release.

```
## [x.y.z] - YYYY-MM-DD
### Added
- 
### Changed
- 
### Fixed
- 
### Permissions / data handling
- (State "No change" or describe it. Update the privacy policy BEFORE shipping any change here.)
```
